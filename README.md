# 🍞 Bakery Project

An online bakery website with a warm, inviting design.

## Features
- Beautiful product display
- Shopping cart functionality
- Responsive design
- Interactive UI

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Live Demo
[View Live Site](https://wadiahm.github.io/Bakery-project/)

## How to Run Locally
1. Clone this repository
2. Open any of these files in your browser:
   - `index.html` - Home page
   - `menu.html` - Menu page
   - `drinks.html` - Drinks page
   - `cart.html` - Shopping cart page
